# Dhwani Shah portfolio

A local static mirror of the published Framer portfolio at `dhwani.framer.ai`, including all six published pages, responsive layouts, original media, fonts, and Framer interaction code.

## Run locally

```sh
npm start
```

Open <http://127.0.0.1:4173>.

## Refresh from Framer

```sh
npm run mirror
npm run check
npm run test:e2e
```

The localized site is stored in `site/`. External portfolio links (email, LinkedIn, Instagram, and the résumé) intentionally remain external.
